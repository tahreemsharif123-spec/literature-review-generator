# VeriLit: Literature Review Generator with Verified Citations

A free tool for MPhil and PhD students. It finds real papers through OpenAlex and Semantic Scholar, verifies every DOI with Crossref, and checks every citation in the draft so no fake reference gets through.

Live site: https://literature-review-generator.netlify.app/

## Deploy
- Every push to `main` deploys `verilit/` to Netlify automatically.
- Hostinger: upload `verilit/` as described in `verilit/DEPLOY.md` to also enable the PHP auto-writer.
